getBill v0.1.0-alpha.17

Last modified: 2026-11-17 18:07 EST

getBill is a command-line tool that reads AWS Cost and Usage Report (CUR 2.0) files in CSV or Parquet format from Amazon S3 and writes Excel workbooks back to Amazon S3, in the same AWS account or another one.

It shows preparing sample files, signing in to two AWS accounts, converting a CSV file and a Parquet file, and opening the finished workbook. About 3½ minutes at the starting speed of 0.5×. Speeds run from 0.25× to 2×, and you can jump to any step.
